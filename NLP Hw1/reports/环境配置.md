# 作业一环境配置记录

配置日期：2026-09-28。

- 运行环境：macOS，Apple Silicon，Python 3.12.14。

## 本机 Git 兼容说明

本机默认 `/usr/bin/git` 调用 Xcode 时遇到库加载错误。本次使用已安装的独立 Git 2.53.0 完成仓库操作：

```bash
/Users/yyyxxxyyy/.cache/codex-runtimes/codex-primary-runtime/dependencies/bin/fallback/git --version
```

这是本机工具链问题；其他机器使用正常的 `git` 即可，不影响实验代码。

## 作业范围与约定

本阶段仅完成 Task 1：Binary Bag of Words 和 Word Frequency，统一使用 Logistic Regression，并在 NYT Test Set 上报告 Accuracy 和 Macro-F1。

作业规定 NYT 随机打乱后按 80% / 10% / 10% 划分训练、验证、测试集。文档没有列出具体随机种子，本实现固定为 42，持久化行索引以便后续任务复用。文档中“对于三种方法”与实际列出的两种方法不一致，按本次明确要求实现两种。
